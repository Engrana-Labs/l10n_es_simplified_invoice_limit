Descripción rápida

Módulo para Odoo 18 que hace visible y editable el ajuste l10n_es_simplified_invoice_limit en Ajustes → Contabilidad / Facturación. Hereda la vista del módulo l10n_es y muestra el bloque que contiene el ajuste. No redefine el campo en res.company.

Requisitos

  • base
  • account
  • l10n_es

Instalación rápida

1. git clone https://github.com/engranalabs/l10n_es_simplified_invoice_limit.git
2. Reinicia Odoo y actualiza la lista de apps (modo desarrollador).
3. Instala el módulo **Límite factura simplificada (ES) - Engrana Labs**.
4. Ve a **Ajustes → Contabilidad / Facturación** y verás el ajuste.
IMPORTANTE: consulta esta entrada de Odoo para decidir qué límite debes establecer:
https://www.odoo.com/es_ES/blog/business-hacks-1/factura-simplificada-en-espana-1231
