# l10n_es_simplified_invoice_limit — Límite factura simplificada (ES)  
**Engrana Labs**

**Repositorio:** Engranalabs / l10n_es_simplified_invoice_limit

---

## Descripción rápida
Módulo para Odoo 18 que hace visible y editable el ajuste **Límite factura simplificada (ES)** en **Ajustes → Contabilidad / Facturación**.  
Hereda la vista de `l10n_es` y muestra el bloque que contiene `l10n_es_simplified_invoice_limit`. No redefine el campo en `res.company`.

---

## Requisitos
- `base`
- `account`
- `l10n_es`

---

## Instalación (rápida)
1. Clona el repo en tu `addons_path`:
   ```bash
   git clone https://github.com/engranalabs/l10n_es_simplified_invoice_limit.git

2. Reinicia Odoo y actualiza la lista de apps (modo desarrollador).
3. Instala el módulo **Límite factura simplificada (ES) - Engrana Labs**.
4. Ve a **Ajustes → Contabilidad / Facturación** y verás el ajuste.
